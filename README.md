# Сайт yevhenkochubei.com.ua — Jekyll + GitHub Pages

## Що всередині
- `_config.yml` — налаштування сайту
- `_layouts/`, `_includes/` — шаблони сторінок
- `_posts/` — статті блогу (щоб додати нову — скопіюй файл, зміни назву
  на `РІК-МІСЯЦЬ-ДЕНЬ-назва-статті.md` і текст)
- `assets/css/style.css` — весь дизайн
- `*.md` у корені — основні сторінки (головна, для чоловіків, тривога і
  стосунки, самодопомога, блог, групи, для компаній, про мене, контакти)
- `CNAME` — вже містить домен `yevhenkochubei.com.ua`

## Розгортання (робиться один раз, ~15 хв)

1. **Створи репозиторій на GitHub**
   - github.com → New repository → назви, наприклад, `yevhenkochubei-site`
   - Публічний репозиторій (для безкоштовного GitHub Pages)

2. **Заливаєш ці файли**
   - Найпростіше: на сторінці репозиторію → "uploading an existing file" →
     перетягуєш усі файли й папки з цього архіву → Commit

3. **Вмикаєш GitHub Pages**
   - Settings → Pages → Source: `Deploy from a branch` → branch `main`,
     папка `/ (root)` → Save
   - GitHub сам збере Jekyll-сайт (нічого встановлювати не потрібно)

4. **Підключаєш домен**
   - Там, де купував домен (реєстратор), у DNS додай:
     - A-записи на IP GitHub Pages (185.199.108.153, 185.199.109.153,
       185.199.110.153, 185.199.111.153) для кореневого домену
     - CNAME-запис `www` → `<твій-акаунт>.github.io`
   - У Settings → Pages вкажи Custom domain: `yevhenkochubei.com.ua` і
     онови (можна залишити як є — файл `CNAME` вже в репозиторії)
   - Онови до "Enforce HTTPS" (з'явиться через кілька хвилин після
     підтвердження DNS)

5. **Перевіряєш у Google Search Console**
   - Оскільки GSC вже підключено до цього домену — нічого додатково
     робити не треба, дані продовжать збиратись
   - Після запуску: Sitemaps → додай `https://yevhenkochubei.com.ua/sitemap.xml`
     (генерується автоматично плагіном jekyll-sitemap)

## Що ще треба доробити перед публікацією
- Вставити реальні ID форм Tally замість `ВАШ_ID_ФОРМИ` (сторінки
  `kontakty.md`, `hrupy.md`, `samodopomoga.md`)
- Створити окремі сторінки для кожного тесту з бібліотеки самодопомоги
  (зараз є посилання-заглушки в `samodopomoga.md`)
- Оновити ціни та дати груп на сторінці `hrupy.md`
- Дописати повний текст двох стартових статей блогу
- Додати фото (кабінет, портрет) в `assets/images/`
